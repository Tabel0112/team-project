# Study App

A Java 11 desktop study workspace for students turning course notes into editable
question/answer sets. Users import text or paste notes, generate with Gemini or
write cards manually, review flashcards, self-assess practice quizzes, retry missed
questions, and save locally or to a Supabase account.

The primary use scene is a student studying at a laptop. The library stays visible
while notes, editing, and practice occupy tabs. Cloud accounts are optional; the
local library works without configuration. API secrets come from `.env`.
