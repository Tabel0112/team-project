# Study App

A Java 11 desktop study workspace for students turning course notes into editable
question/answer sets. Users import PDFs, import text, or paste notes, generate with Gemini or
write cards manually, review flashcards, and save locally when closing the app.

The primary use scene is a student studying at a laptop. The library stays visible
while notes, editing, and practice occupy tabs. The local library works without configuration; cloud and manual save controls are hidden. API secrets come from `.env`.
