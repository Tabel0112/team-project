# Desktop interface

Mode: Operate. Use the native Swing look and feel, including platform fonts,
keyboard focus, selection, and accessibility conventions. This is a desktop tool
with a persistent study-set list and task tabs, rather than a marketing surface.

The workspace uses 24 px outer insets, 18 px tab padding, 12–20 px section gaps,
and a 27 pt bold workspace title. Native controls carry their system contrast and
interaction states. Question and answer fields wrap text and scroll. Library and
editor split panes resize independently. Minimum window size is 960 × 700.

Dialogs are reserved for file selection, account credentials, confirmations, errors,
and focused practice sessions. Long network work runs off the event dispatch thread
with a visible status message and disabled workspace. Errors preserve local changes.
